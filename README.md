# LEAGUE WORLD

가상의 전 세계 야구 생태계를 현실 야구 구조에 가깝게 시뮬레이션하는 프로젝트입니다.

핵심은 두 가지입니다.

1. **살아 있는 야구 세계**: 선수, 감독, 학교, 구단, 리그가 시간에 따라 성장·이동·은퇴하며 기록과 역사를 쌓습니다.
2. **감독 커리어 플레이**: 플레이어는 감독이 되어 구단을 맡고 선수단 운영, 영입, 트레이드, 계약, 드래프트, 1/2군 관리, 이직과 경질까지 경험합니다.

## 핵심 원칙

- 선수 커리어는 직선형이 아닙니다. 중학교에서 야구를 그만둘 수도 있고, 평생 2군에 머물 수도 있으며, 해외 진출 없이 국내에서만 뛰다 은퇴할 수도 있습니다.
- 감독도 하나의 인물입니다. 구직, 계약, 이직, 해외 진출, 경질, 무직, 국가대표 감독 경력이 모두 기록됩니다.
- 각 나라의 야구 구조는 현실 야구 구조를 참고하되, 구단·선수·학교·역사는 가상으로 구성합니다.
- 모든 서비스는 하나의 World DB를 공유합니다.

## 서비스 구상

- LEAGUE — 전체 메인
- PRO — 국가별 프로야구
- AMATEUR — 중학/고교/대학
- PLAYER — 선수 통합 DB
- TEAM — 학교/구단
- LIVE — 일정/결과/박스스코어
- STATS — 기록실
- PROSPECT — 유망주
- DRAFT — 드래프트
- MARKET — FA/트레이드/해외이적
- NEWS — 야구 뉴스
- WORLD — 국가대표/국제대회
- HISTORY/WIKI — 야구 역사
- BOARD — 세계 관리자

## LEAGUE Web v0.1 실행

브라우저에서 현재 World Engine을 직접 보고 조작하는 개발용 UI가 포함되어 있습니다.
상태는 브라우저 메모리에서 동작하며 새로고침하면 같은 seed의 개발용 세계로 다시 생성됩니다.

```powershell
npm install
npm run dev
```

기본 접속 주소:

```text
http://localhost:5173
```

검증 명령:

```powershell
npm run typecheck
npm test
npm run build
```
