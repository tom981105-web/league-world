# LEAGUE WORLD — Product Spec v0.1

## 한 문장 정의

현실 야구의 세계 구조를 참고한 완전 가상 야구 세계에서, 수많은 선수와 감독이 각자 다른 커리어를 살아가고 사용자는 감독으로 구단을 운영하며 자신의 지도자 경력을 쌓는 장기 시뮬레이션 플랫폼.

## 핵심 재미

### 1. 세계를 구경하는 재미

- 오늘의 경기 결과
- 갑작스러운 유망주 등장
- 드래프트 실패와 대박
- 2군 선수의 늦은 1군 데뷔
- 해외 진출과 복귀
- 감독 경질과 이직
- 학교/구단의 흥망
- 수십 년 뒤 누적된 역사

### 2. 감독으로 플레이하는 재미

플레이어 감독은 구단 규모와 계약 권한에 따라 다음 업무를 수행한다.

- 로스터 구성
- 1군/2군 또는 마이너 이동
- 라인업/선발 로테이션/불펜 역할
- 선수 영입/방출
- 트레이드 협상
- FA 계약
- 외국/해외 선수 계약
- 드래프트/스카우팅
- 유망주 육성
- 코칭스태프 구성(후속 단계)
- 경기 운영(후속 단계)

감독 자신도 계약 대상이다.

- 구직
- 구단의 감독 제안
- 재계약
- 이직
- 시즌 중 타 구단 영입
- 경질
- 무직
- 해외 진출
- 국가대표 감독

## 세계

초기 버전은 한국을 깊게 구현하고, 이후 미국·일본부터 확장한다.
장기적으로는 대만, 멕시코, 중남미, 호주, 유럽 등도 포함할 수 있다.

중요: 나라별 리그/육성 구조는 하나로 통일하지 않는다.
각 나라의 현실 야구 생태계와 비슷한 구조를 가진다.

## 선수 커리어

커리어는 정해진 단계 목록을 순서대로 통과하는 것이 아니다.

예시 A:
중학 → 고교 → 대학 → 미지명 → 은퇴

예시 B:
고교 → 프로 2군 → 방출 → 독립리그 → 재입단 → 31세 1군 데뷔

예시 C:
고교 → 프로 → 국내 MVP → 국내 잔류 → 은퇴

예시 D:
고교 → 프로 → 해외 진출 → 마이너 → 방출 → 국내 복귀

예시 E:
중학교 → 야구 중단

## 데이터 영속성

한 번 세계에 존재한 선수/감독/팀/학교/시즌의 핵심 이력은 역사 DB에 남는다.
은퇴한 선수도 검색 가능하며 과거 기록, 소속팀, 수상, 이적, 학교 이력을 확인할 수 있어야 한다.
